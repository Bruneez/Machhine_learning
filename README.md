# 💡 Machine Learning Projects Collection

This repository contains a collection of machine learning mini-projects and notebooks developed using **Google Colaboratory**. Each folder represents a different algorithm or technique applied to datasets for learning, evaluation, and model experimentation.

## 📂 Project List

- **Algorithm Evaluation**  
  Evaluation metrics and comparisons of machine learning algorithms.

- **Classification Project**  
  Time series classification using supervised learning models.

- **Feature Selection with Mutual Info Score**  
  Selecting features using Mutual Information Score for improved model accuracy.

- **Gradient Boosting Classification (GBC)**  
  Using Gradient Boosting techniques for classification problems.

- **Hierarchical Clustering**  
  Time series data clustering using hierarchical methods.

- **K-Means Clustering**  
  Implementation of K-Means clustering on sample data.

- **KNN (K Nearest Neighbor)**  
  Applying KNN algorithm for regression and classification tasks.

- **Logistic Regression**  
  Binary classification using logistic regression.

- **Mobile Price Classification**  
  Predicting mobile price range using supervised learning (GBC model).

- **Random Forest Classification (RFC)**  
  Building and evaluating random forest classifiers.

- **Support Vector Machine (SVC)**  
  Classification using Support Vector Machine techniques.

- **Time Series Decomposition**  
  Analyzing and decomposing time series data.

- **Decision Tree Regression**  
  Implementing decision trees for regression analysis.

- **Decision Tree Classification**  
  Classification using decision tree models.
